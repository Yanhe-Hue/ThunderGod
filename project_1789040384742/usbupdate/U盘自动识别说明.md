# U盘A/B原名识别与日期验证

适用于 local_pair 和 usb_pair_smoke，配置为 stress.package_source = "usb_scan"。此时不再使用 packages 中旧的路径、expected_date 或 expected_qnx；目标日期只取原始包文件名。

1. 将两个不同日期的原始版本ZIP放到U盘根目录或普通子目录，保留下载时的名字。不要放到 USB_UPDATE 目录。
2. 启动压测。脚本切U盘到电脑、确认盘符枚举后，扫描ZIP文件名，按日期由旧到新作为A/B，记录文件名和预期日期。只扫描一次，本次循环固定使用这两个包。
3. 每轮复制当前原包为 USB_UPDATE/Update.zip，保留原包名字和文件。
4. 升级、激活、重启，上电等待120秒后检测ADB，读取车机QNX日期，与当前原始包名日期比较。日期不同立即停止并留证，不执行本轮冒烟或下一轮。
5. 日期通过后，local_pair进入下一轮；usb_pair_smoke先执行冒烟。ATS正常完成但用例失败，记录后继续，原有规则不变。

支持包名含 YYYYMMDD、YYYY-MM-DD、YYYY_MM_DD、YYYY.MM.DD，例如 full_userdebug_20260914_080544_all_renault.zip。不会使用今天日期、文件修改时间或目录名代替。缺日期、非法日期或包名含多个不同日期的ZIP会列出原因并排除；最终必须恰好识别两个不同日期的包，否则停止，不猜测挑选。

忽略USB_UPDATE、系统目录、隐藏目录、链接及.part文件。有更多带日期的ZIP时请移走额外文件。包名日期应对应该包QNX构建日期，不能通过改名字把失败的校验变成通过。

首次ZIP CRC与SHA256校验仍保留；文件名扫描不解压整个包，无需读取包内版本信息。local_pair仍需电脑缓存空间。新电脑只需配置硬件/环境，无需每次填写A/B路径和日期。

云盘每日升级入口未改变，本次优化范围为两种本地A/B压测。
